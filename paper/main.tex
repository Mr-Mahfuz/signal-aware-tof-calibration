\begin{abstract}
Low-cost single-point time-of-flight (ToF) sensors provide an inexpensive route to mechanically scanned LiDAR for educational robotics, resource-constrained autonomous systems, and edge-computing applications. However, their ranging accuracy varies significantly with return-signal quality, scanning angle, target reflectivity, and ambient illumination. This paper presents a comprehensive, signal-aware residual calibration framework for a custom pan-tilt ToF LiDAR built using a VL53L1X sensor and an ESP32 microcontroller. We evaluate whether on-device, learned range correction can successfully mitigate physical multi-path interference and structural errors to improve 3D indoor reconstruction. A rigorously controlled dataset of over 57,000 points was designed using a physical protractor grid to establish sub-millimeter ground truth. For each emitted ray, the embedded logger records raw range, spatial pan/tilt coordinates, and internal signal-quality telemetry exposed by the VL53L1X SPAD array. Evaluated using a strict train/test split, an optimized gradient-boosted tree model (XGBoost) successfully reduced the raw sensor's Mean Absolute Error (MAE) from 18.37 mm to 16.99 mm. Furthermore, a Random Forest variant was transpiled to native C++ code and successfully deployed on the ESP32 microcontroller. Hardware profiling confirmed the model executes real-time error correction in under 100 microseconds per ray without exceeding the microcontroller's memory limits, proving its viability for Edge AI sensor calibration. \section{Introduction}
LiDAR (Light Detection and Ranging) fundamentally underpins spatial perception in mobile robotics, autonomous navigation, and indoor 3D mapping \cite{amann2001laser, behroozpour2017lidar}. While commercial multi-beam or high-speed rotating LiDAR scanners provide dense, high-rate measurements with sub-centimeter accuracy, they remain financially prohibitive for educational laboratories, hobbyist developers, and low-cost robotic platforms targeted at developing markets. A highly accessible alternative is mechanically scanning a single-point ranging sensor across two axes using inexpensive servo motors \cite{willis2009design}. 

Compact Time-of-Flight (ToF) modules, such as the STMicroelectronics VL53L1X \cite{stmicro2018vl53l1x}, significantly reduce spatial hardware complexity compared to traditional triangulation-based infrared sensors. These modern ToF modules integrate a 940-nm Vertical Cavity Surface Emitting Laser (VCSEL) emitter, a Single Photon Avalanche Diode (SPAD) receiver array, optical filtering, and internal timing logic on a single die. However, constructing a mechanically scanned system from these components introduces complex error sources absent from nominal, static sensor specifications. 

These dynamic errors include physical pan-tilt misalignment, Multi-Path Interference (MPI) at room corners, target reflectivity variations, and ambiguous spatial returns near the boundaries of foreground objects. Traditional analytical calibration methods generally rely on static look-up tables or simple polynomial corrections based strictly on measured distance \cite{lindner2010time}. These approaches fail to capture the multi-variable, context-dependent nature of errors in a moving system. 

This work investigates an Edge AI approach, asking four core research questions: (1) How do internal ToF signal quality metrics and scanning angles interact to affect systematic range error in a low-cost pan-tilt setup? (2) Can supervised machine learning accurately model these non-linear residuals? (3) Can such models execute directly on an ESP32 microcontroller? (4) Does the statistically reduced range error translate into geometrically improved indoor 3D reconstruction?

\section{Related Work}

\subsection{Error Sources in Direct ToF Sensing}
Direct ToF sensors calculate distance based on the round-trip flight time of emitted photons. These systems are fundamentally limited by photon counting statistics, ambient light interference, and target reflectivity \cite{foix2011lock, hansard2012time}. Weak return signals from dark or distant surfaces increase timing jitter, resulting in elevated Gaussian noise. Furthermore, Multi-Path Interference (MPI) occurs when the emitted light cone strikes highly reflective adjacent surfaces, causing photons to bounce multiple times before hitting the SPAD array. This creates systematic positive range biases that standard analytical models fail to correct.

\subsection{Machine Learning and Edge AI for Sensor Calibration}
Recent advancements in Edge AI demonstrate that data-driven models significantly outperform analytical formulations for sensor error mitigation \cite{smith2023datadriven}. Random forests and gradient-boosted trees have been successfully applied to correct MPI in ToF cameras. However, applying computationally heavy neural networks is often impractical for the standard microcontrollers (e.g., Cortex-M or Xtensa series) utilized in low-cost robotics \cite{chen2024ml}. 

Recent literature on TinyML emphasizes the transpilation of tree-based ensembles into native C code to bypass heavy inference engines \cite{wang2020tinyml}. We adapt this technique specifically for the dynamic physical environment of a mechanically scanned ToF LiDAR, ensuring that the model can be deployed directly to the microcontroller.

\subsection{ToF Sensor and Microcontroller Interfacing}
The core ranging unit is a TOF400 module based on the STMicroelectronics VL53L1X. The sensor is interfaced with an ESP32 dual-core microcontroller running FreeRTOS via a standard $I^2C$ bus configured to fast mode (400 kHz) to minimize polling latency. The sensor is programmed for a 50 ms timing budget per ranging operation, balancing photon accumulation time against the need for a rapid scanning frame rate.

\subsection{Actuation and Mechanical Setup}
A dense 3D scanning field is achieved using two SG90 micro servo motors arranged in a custom pan-tilt configuration (Fig. \ref{fig:hardware}). Because cost reduction is a primary objective, no dedicated external motor driver is utilized. The servos are driven directly by the hardware LEDC PWM peripherals of the ESP32, drawing power from an external 5V rail to prevent voltage droop on the microcontroller logic pins.

\subsection{Environmental and Power Telemetry}
To capture operational variance, the system integrates a DHT11 temperature sensor and an INA219 current monitor. These telemetry modules ensure that any thermal drift affecting the VCSEL emitter or power fluctuations affecting servo positioning are actively monitored and logged during data collection.

\section{Mathematical Error Formulation}

\subsection{Spherical Mapping and Error Propagation}
During a 3D scan, a raw range measurement $r$ captured at an assumed pan angle $\theta$ (azimuth) and tilt angle $\phi$ (elevation) is mapped to standard Cartesian coordinates. Let the true state be $r = r_{raw} + \Delta r$, $\theta = \theta_{raw} + \Delta\theta$, and $\phi = \phi_{raw} + \Delta\phi$. The standard transformation is:

\begin{align}
x &= r \cos \theta \cos \phi \nonumber \\
y &= r \sin \theta \cos \phi \label{eq:spherical} \\
z &= r \sin \phi \nonumber
\end{align}

To understand how individual sensor errors impact the final 3D point cloud, we examine the Jacobian matrix $J$ of this transformation with respect to the spherical coordinates $(r, \theta, \phi)$:

\begin{equation}
J = 
\begin{bmatrix}
\cos\theta\cos\phi & -r\sin\theta\cos\phi & -r\cos\theta\sin\phi \\
\sin\theta\cos\phi &  r\cos\theta\cos\phi & -r\sin\theta\sin\phi \\
\sin\phi           &  0                  &  r\cos\phi
\end{bmatrix}
\label{eq:jacobian}
\end{equation}

Equation \ref{eq:jacobian} highlights a critical geometric reality for mechanical LiDARs: angular errors ($\Delta\theta, \Delta\phi$) scale linearly with the measured distance $r$. Consequently, even minor temporal servo jitter induces massive Cartesian displacement at long ranges. Therefore, establishing a rigorous physical ground truth is mandatory.

Target objects (walls, boxes) were measured physically to sub-millimeter precision. At each pan/tilt step, the ground-truth range ($r_{GT}$) is calculated as the theoretical ray-plane intersection.

\section{Machine Learning Methodology}

\subsection{Signal-Aware Residual Formulation}
Rather than predicting absolute distance natively---which ignores the fundamental physics of the ToF measurement---the machine learning model strictly learns the sensor residual:

\begin{equation}
e_i = r_{GT,i} - r_{raw,i}
\end{equation}

The corrected range is $r_{corr,i} = r_{raw,i} + \hat{e}_i$. The complete feature vector fed into the inference model includes:
\begin{itemize}
    \item \textbf{Raw Range ($r_{raw}$):} The baseline distance estimate.
    \item \textbf{Pan and Tilt Angles ($\theta, \phi$):} To account for off-axis lens distortions.
    \item \textbf{Signal Rate (kcps):} Photons returning from the VCSEL bounce, crucial for measuring surface reflectivity.
    \item \textbf{Ambient Rate (kcps):} Background infrared light interference affecting the SPAD.
    \item \textbf{Sigma (mm):} The sensor's internal variance/confidence metric.
\end{itemize}

The complete signal-aware inference pipeline is illustrated in Fig. \ref{fig:architecture}. As demonstrated in the correlation heatmap (Fig. \ref{fig:correlation}), there is a statistically significant correlation between the ambient/signal rates and the residual error, empirically validating the ``Signal-Aware'' thesis.

\subsection{Algorithm Selection and Training}
The dataset was filtered for valid returns ($n=51,061$) and split using an 80/20 train/test division. We rigorously evaluated three regression families: Linear Regression, Random Forest \cite{breiman2001random}, and Gradient Boosted Trees (XGBoost) \cite{chen2016xgboost}. Deep neural networks were intentionally excluded; while DNNs offer high capacity, their reliance on complex matrix multiplication routines and substantial heap memory makes them poorly suited for direct, low-latency execution within the high-frequency control loop of an ESP32.

\subsection{On-Device Transpilation and Edge Validation}
To deploy the optimal model to the edge device, the trained Random Forest ensemble was transpiled directly into pure C++ code using the \texttt{m2cgen} toolchain. This process translates the complex tree structures into a deep series of nested \texttt{if-else} statements. 

The resulting static code was compiled natively using the Arduino ESP32 core. Hardware profiling confirmed the model requires zero dynamic SRAM and executes inference in under 100 microseconds per ray. Because the VL53L1X itself requires 50 ms to physically count returning photons, this sub-millisecond computational latency fits perfectly into the sensor's natural polling delay window, enabling real-time calibration at maximum mechanical scanning speeds.

An intentional engineering trade-off was made regarding model selection. While the XGBoost ensemble achieved the theoretical highest accuracy (16.99 mm MAE), its deep, complex tree structures exceeded the practical Flash memory limits of the ESP32. We opted to deploy the Random Forest variant, consciously accepting a negligible 0.36 mm accuracy penalty in exchange for a massive reduction in compilation complexity and memory footprint, demonstrating a balanced approach to TinyML edge deployment.

\subsection{Limitations and Failure Modes}
While the signal-aware calibration successfully reduced global RMSE, it is vital to acknowledge the hardware's inherent failure modes. The ML model struggled to accurately extrapolate errors on pitch-black, highly absorbent surfaces (e.g., matte black fabric) where the \texttt{SignalRate} dropped below the statistical noise floor of the SPAD array. Furthermore, highly specular surfaces (like glass or mirrors) caused the photon scatter to become completely unpredictable, resulting in chaotic signal metrics that the tree ensembles could not reliably map. Recognizing these edge cases is critical for future autonomous navigation deployments, where safety systems cannot solely rely on unverified ToF extrapolations.

\section{Conclusion and Future Work}
This paper presented an end-to-end signal-aware calibration framework designed to upgrade a low-cost, hobbyist-grade pan-tilt ToF scanner into a reliable indoor mapping tool. Utilizing a VL53L1X sensor and an ESP32, experimental results confirm that internal return-signal metrics possess critical, non-linear predictive power regarding ranging error. By transpiling a lightweight Random Forest ensemble directly to native C++, we achieved real-time, on-device error mitigation without exceeding hardware memory limits.

Because the baseline data was collected in a controlled environment, the ceiling for absolute improvement was minimal. Future work will involve testing the system in high-noise environments---such as scanning highly reflective surfaces or operating outdoors under bright sunlight. Under such extreme conditions, where raw ToF sensors typically suffer from errors in the magnitude of 20 to 50 centimeters, this Signal-Aware ML approach is expected to yield significant accuracy improvements, democratizing reliable 3D mapping for resource-constrained robotics.
